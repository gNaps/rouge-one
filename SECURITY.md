# Security

Rouge One 0.1 is a release candidate. Report vulnerabilities privately to the maintainer at gabriele.nap@gmail.com, or use a private GitHub vulnerability report when enabled. Include affected version, reproduction and impact. Do not put passwords, real access tokens or customer data in public issues.

Only the latest released version is targeted for security fixes. Dependency audit and secret scanning are automated. Complete a real Google-provider smoke test before announcing a production release.

Administrators own deployment configuration, TLS, database access and backup protection. Local defaults are for localhost demonstrations. Do not expose Mailpit or the database publicly.
