# Changelog

## 0.1.0 — unreleased

- Unified API, administrator panel and hosted login in a pnpm workspace.
- Added persistent PostgreSQL deployment, external-database configuration, preflight and additive migration.
- Added token-protected first administrator setup, cookie sessions and CSRF validation.
- Simplified first-run setup with a private link generated by the installation command; administrators enter only email and password.
- Separated administrator and project identities; added PKCE authorization-code exchange.
- Implemented password login, Google state/PKCE, hashed single-use magic links, verification and password reset.
- Added project onboarding, tenant login, integration example, regression tests and operator documentation.
- Completed dashboard and project-form styling, responsive navigation, integration panels and record lists; aligned legacy color utilities with the current theme and removed prototype footer content.

Existing accounts are preserved when upgrading from the complete historical schema. Sessions and legacy magic links are invalidated. Project callbacks now receive authorization codes rather than URL JWTs. Legacy administrative signup is disabled. Project roles and permissions support creation, editing and deletion, reusable grants, default-role selection and user-role assignment. User access tokens include role names and permission keys; authorization changes revoke affected sessions. Additional providers remain unavailable.
